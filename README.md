# Лабораторная работа № 2 — многопоточное умножение матриц

В архив входят исходный код Java, CSV с отдельными замерами, сводные CSV и графики.

## Содержимое

- `src/Main.java` — чтение аргументов, запуск генератора, умножение матриц, рабочие потоки, прогресс, контрольная сумма и измерение времени.
- `src/MatrixGenerator.java` — отдельный процесс генерации матриц и передача данных родительскому процессу через pipe в двоичном формате.
- `data/raw/normal_2000_raw.csv` — 30 исходных измерений обычного умножения (6 значений числа потоков × 5 повторов).
- `data/raw/triangular_2000_raw.csv` — 60 исходных измерений треугольной матрицы (2 распределения × 6 значений числа потоков × 5 повторов).
- `data/summary/` — итоговые таблицы: из пяти измерений в каждой группе исключены минимальное и максимальное значения, по оставшимся трём рассчитано среднее время.
- `graphs/` — графики времени, ускорения и эффективности.

## Требования

- JDK с `javac` и `java` в PATH. Эксперименты в данном проекте запускались пользователем на Windows 11 x64 с OpenJDK 27.0.1.0.2.
- Дополнительные библиотеки не требуются.

## Сборка в Windows PowerShell / терминале IntelliJ IDEA

Перейдите в папку `src`, где находятся оба `.java` файла:

```powershell
cd src
javac Main.java MatrixGenerator.java
```

## Запуск

Обычное умножение `A(n × m) * B(m × k)`:

```powershell
java Main normal 2000 2000 2000 8
```

Формат: `java Main normal n m k T`, где `T` — количество рабочих потоков.

Нижнетреугольная матрица A; статическое распределение строк:

```powershell
java Main triangular 2000 2000 12 static
```

Динамическое распределение строк:

```powershell
java Main triangular 2000 2000 12 dynamic
```

Формат: `java Main triangular n k T static|dynamic`. Матрица A имеет размер `n × n`, но в строке `i` сохраняются только `i+1` элементов; матрица B имеет размер `n × k`.

Генератор использует фиксированное seed, поэтому при одинаковом режиме и размерах исходные данные воспроизводятся. В выводе отображаются время генерации, записи в pipe, полной подготовки данных, умножения и контрольная сумма.

## Методика обработки замеров

Для каждого количества потоков сделано 5 запусков; в сводной таблице удалены минимальное и максимальное значения, среднее вычислено по оставшимся 3. Ускорение рассчитано как `S(T) = t(1) / t(T)`, эффективность — как `E(T) = S(T) / T`. CSV используют точку с запятой как разделитель столбцов; десятичные значения в исходных Windows-замерах представлены с запятой.

Контрольная сумма обычного умножения в серии: `162014496253`. Для треугольной серии: `81057662791`. Они совпали во всех соответствующих замерах.
